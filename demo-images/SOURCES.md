# Sample images for demonstrating the two upload bonuses

These are optional public-domain demonstration files. Upload them from an Add/Edit form; the database seed script does not download any files or use extra SQL columns.

- `jane-austen.jpg`: colorized historical portrait of Jane Austen. Source: [Digital Jane Austen, Jane Austen Portrait in Color](https://digitalausten.omeka.net/items/show/9). The source identifies the image as public domain and traces it to [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Jane_Austen_coloured_version.jpg).
- `pride-and-prejudice.png`: illustrated 1894 title page used as a sample book image. Source: [Project Gutenberg, Pride and Prejudice](https://www.gutenberg.org/ebooks/1342), [image file](https://www.gutenberg.org/cache/epub/1342/images/front.png). The record identifies the edition as public domain in the USA. The scan names Hugh Thomson as illustrator and George Allen as publisher.

The image files are downloaded originals. The website normalizes copies to PNG when they are uploaded. The title-page image is a demonstration book image, not a photograph of a modern cover. Local prices in the database are invented classroom test values.

For a quick demo, edit Jane Austen (author ID 2) and upload `jane-austen.jpg`; edit Pride and Prejudice (book ID 103) and upload `pride-and-prejudice.png`. These two uploads are already present in the prepared local website. A clean ZIP installation starts without uploaded files, and includes these samples for re-uploading.
